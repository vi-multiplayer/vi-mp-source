# Security policy

## Supported versions

There are no released software versions yet. Security reports about future components will be handled by the maintainers.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's **Report a vulnerability** feature on the repository when it is available. If that feature is unavailable, contact a repository owner privately through GitHub and include only the minimum details needed to establish the report.

Do not include game files, personal data, credentials, or unrelated third-party vulnerabilities. The maintainers will acknowledge reports when possible, assess scope and impact, and coordinate a fix and disclosure with the reporter.

## Scope

Reports should concern code or infrastructure maintained by this project. The project does not provide security testing authorization for third-party games or services.
